APLIKASI PEMINJAMAN ALAT (PHP Native + MySQL)

CARA PASANG
1. Jalankan XAMPP: start Apache dan MySQL.
2. Salin folder "peminjaman_alat" ke C:\xampp\htdocs\
3. Buka http://localhost/phpmyadmin -> tab Import -> pilih database.sql -> Go.
4. Buka http://localhost/peminjaman_alat/
5. Jika MySQL memakai password, ubah di config.php.
